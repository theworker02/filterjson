# filterjson

Filter identifiers and json tokens for idempotent workflows.

**Site:** https://theworker02.github.io/filterjson/

## Install / run

```bash
git clone https://github.com/theworker02/filterjson.git
cd filterjson
node src/cli.js
node --test
```
